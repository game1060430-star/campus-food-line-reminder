# Excel 規則與欄位策略

> 欄位與星號依 `data/templates/` 官方樣板。實際現有成功使用資料在 `data/current/`。

## A. 預排菜單 — PreMenuExcelExample.xlsx
工作表：`菜色清單`

| 欄位 | 系統規則 |
|---|---|
| 學校名稱* | 必填，分店自動帶入 |
| 供餐地點* | 必填，分店自動帶入 |
| 餐廳名稱* | 必填，分店自動帶入 |
| 供餐日期* | 必填 |
| 菜色類別 | 選填 |
| 菜色名稱* | 必填 |
| 食材 | 選填；可由配方自動組字串，但允許空白 |
| 熱量* | 必填 |

## B. 每日進貨食材 — PrerestaurantingredientExcelExample.xlsx
工作表：`每日進貨食材`

必要：學校名稱、供餐地點、餐廳名稱、供餐日期、進貨日期、產品名稱、食材名稱、食材原產地(國)、供應商名稱。

其餘全部選填：製造商、生產日期、有效日期、批號、加工食品、非基改黃豆、非基改玉米、食材驗證標章、驗證號碼、重量、單位、熱量、供應份數。

實際目前資料證明許多列可將生產日/有效日/批號/標章/重量/單位/熱量留空。

## C. 調味料存貨 — seasoningstockdataCollegeExcelExample.xlsx
工作表：`Sheet1`

必要：學校名稱、供餐地點、餐廳名稱、調味料名稱、進貨日期、開始日期、結束日期、供應商。

其餘選填：生產日期、有效日期、製造商、驗證標章、驗證號碼、批號、產品名稱、重量、單位、非基改黃豆/玉米、加工品。

注意：目前實際調味料檔的欄名出現 `基改黃豆` / `基改玉米`，官方樣板為 `非基改黃豆` / `非基改玉米`。**Exporter 必須以官方 template 欄名為準，Importer 要兼容這種歷史欄名差異。**

## D. 供應商 — supplierExcelExample.xlsx
工作表：`Data`
欄位：供應商名稱、負責人、公司統編、地址、電話。官方樣板無星號。
系統最低只要求供應商名稱，其他選填。

## 輸出技術要求
1. Import 官方 template，從正確資料起始列寫值。
2. 不刪除/改名參考工作表。
3. 不改變欄位順序。
4. 保留 workbook 中的 validation/reference sheets/格式，除非經測試確認官方匯入不依賴。
5. 日期輸出格式需與樣板/目前成功檔案相容；不要依 Excel serial number 本身做商業判斷。
6. 只有使用者有值或規則要求時才填選填欄位，不自動補虛假資料。
7. 匯出前 validation 可阻擋缺必要欄位，但選填欄位缺少不得阻擋。
8. 每次 export 保存 hash、時間、分店、日期區間與來源資料版本，方便 audit。
