# LINE OA + LIFF 手機 UX

## 原則
LINE 是入口，不等於所有東西都用純文字聊天。多選、月曆、配方、批次資料使用 LIFF，避免一問一答太慢。

## Rich Menu
建議 6 格：
1. 今日狀態
2. 菜單
3. 新增菜色
4. 進貨
5. 食材/調味料
6. 上傳狀態

## 今日狀態
顯示目前分店或全部分店：
- 今日是否營業
- 菜單是否完整
- 必填資料錯誤數
- 上傳是否成功
- CAPTCHA/登入是否需要介入
只突出異常。

## 分店切換
支援「目前分店」與「全部分店」。管理者可有不同權限。

## 新增菜色
LINE 按鈕 -> LIFF：
- 菜色名稱*、熱量*、類別選填
- 多選既有食材 / `+ 新增食材`
- 多選既有調味料 / `+ 新增調味料`
- 非必要欄位折疊
儲存後回 LINE：`要加入哪些日期？`，選單日/多日/區間/營業日。

## 修改菜單
可看今天/明天/未來7天/選日期。
異動確認畫面要列：分店、日期、增加/移除菜色、受影響 upload task。使用者按確認後才寫。

## CAPTCHA
LINE Push：
`A校需要登入驗證 [立即驗證]`
LIFF 顯示 CAPTCHA 圖片 + 單一輸入框 + 確認。
提交後顯示：已送出/驗證失敗需新圖/任務成功。
不要在 LINE 對話訊息裡要求或回傳官方密碼。

## 異常通知
- `A校 9/15 每日食材缺少「雞胸原產地」 [修正]`
- `B校登入 Session 已失效 [立即驗證]`
- `C校預排菜單上傳失敗 [查看原因]`

## 自然語言（第二階段）
可解析：「下週一到五 A店加牛肉丸」。
解析結果只能產生 draft command，回覆變更摘要 + 確認/取消；確認前不得寫正式 DB 或送官方平台。
